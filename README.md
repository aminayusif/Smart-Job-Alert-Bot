# Smart Job Alert Telegram Bot 🤖💼

A Smart Job Alert Telegram Bot that recommends relevant job postings based on user skills using NLP and Machine Learning.

## 🚀 Features
- Telegram-based job search
- NLP-powered job matching
- TF-IDF + Cosine Similarity
- Real-time job recommendations

## 🧠 Machine Learning Approach
- Text preprocessing
- TF-IDF Vectorization
- Cosine similarity for matching user profiles to job descriptions

## 🏗 Project Architecture
Telegram Bot → FastAPI Backend → ML Matching Engine

## 📊 Dataset
Kaggle Job Postings Dataset

## 🛠 Tech Stack
- Python
- scikit-learn
- pandas
- FastAPI
- Telegram Bot API

## ▶️ How to Run
1. Clone repo
2. Install requirements
3. Set Telegram token
4. Run backend
5. Start bot
